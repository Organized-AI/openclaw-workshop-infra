# Architecture Docs

These HTML files are generated design artifacts from the Claude Desktop session.
They render as interactive documentation with sticky navigation.

| File | Description |
|------|-------------|
| `openclaw-gateway-hybrid-v2.html` | Main architecture doc — CF Queue + DO + prompt_logs |
| `openclaw-part1-harness.html` | Part 1 event presentation (16 slides) |
| `openclaw-gateway-architecture.html` | Gateway overview + WhatsApp flow |
| `openclaw-part1.html` | Original Part 1 deck |

## Adding docs locally

After cloning, copy the HTML files from Claude Desktop Downloads:
```bash
cp ~/Downloads/openclaw-gateway-hybrid-v2.html docs/
cp ~/Downloads/openclaw-part1-harness.html docs/
cp ~/Downloads/openclaw-gateway-architecture.html docs/
cp ~/Downloads/openclaw-part1.html docs/
```
